## กติกาใหม่ (C# `FillAllocateUsageAmounts` ใน `BudgetService.GetBudgetOverlapYearCentralList`)

1. ตัดแถวซ้ำด้วย Id
2. รวมเป็น "เอกสาร" ตามสาย PR → PO จาก `OAGPO_TRANSACTION_STATUS_V` (carryfwd = เลขที่เงินกันของใบ)
3. แต่ละเอกสารใช้เฉพาะ Overlapround ล่าสุดที่บันทึกไว้
4. เอกสารที่เข้าขั้นเบิกจ่าย (มีเลขที่จ่าย หรือมีใบรับของ + ใบแจ้งหนี้) → ยอดขยายลง "เบิกจ่าย"
   ไม่งั้น EXPAND_PR → ไม่มีหนี้, EXPAND_PO → มีหนี้; CANCEL_* → คืน เสมอ
