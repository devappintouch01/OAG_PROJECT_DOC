# Roadmap การแก้ไข: ปุ่ม 3 ปุ่มหน้าโอนเงินจัดสรรงบประมาณต้องอยู่แถวเดียวกัน

## สาเหตุของปัญหา

**ไฟล์ที่เกี่ยวข้อง:**
`OAGBudget\Views\Budget\BudgetAllocateTransferDetail.cshtml` บรรทัด 256–269

**สาเหตุหลัก:**
ปุ่มทั้ง 3 ปุ่ม (`อัพเดทงบประมาณ`, `เลือกรายการงบประมาณ`, `ลบรายการ`) อยู่ใน `<div class="mt-3">` ที่ไม่มีการกำหนด flex หรือ nowrap ทำให้ปุ่มสามารถ wrap ขึ้นบรรทัดใหม่ได้เมื่อพื้นที่ไม่พอ

**การคำนวณพื้นที่:**
- ความกว้างหน้าจอ: 1528px
- Sidebar: ~250px → Content area: ~1278px
- `col-md-4` = 1278 ÷ 3 = ~426px (พื้นที่คอลัมน์ปุ่ม)
- ความกว้างรวมของปุ่มทั้ง 3 ปุ่ม (รวม gap): ~427px
- ผลลัพธ์: ปุ่มที่ 3 (`ลบรายการ`) เกินพื้นที่เล็กน้อย จึง wrap ลงบรรทัดที่ 2

## แผนการแก้ไข

### วิธีที่แนะนำ: เพิ่ม `d-flex flex-nowrap gap-1` ให้ div ที่ห่อปุ่ม

**บรรทัดที่แก้:** บรรทัด 259

**ก่อนแก้:**
```html
<div class="mt-3">
```

**หลังแก้:**
```html
<div class="mt-3 d-flex flex-nowrap gap-1 justify-content-end">
```

**เหตุผล:**
- `d-flex` + `flex-nowrap` บังคับให้ปุ่มทั้งหมดอยู่แถวเดียวกัน ไม่ว่าพื้นที่จะแคบแค่ไหน
- `gap-1` เพิ่มระยะห่างระหว่างปุ่มแบบ Bootstrap utility (แทน margin เดิม)
- `justify-content-end` รักษาการจัดชิดขวาของกลุ่มปุ่ม
