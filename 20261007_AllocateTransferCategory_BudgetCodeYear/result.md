# โอนจัดสรร — modal "เลือกรายการงบประมาณ" ขึ้นรายการเบิ้ล คนละรหัสงบ ยอดเท่ากัน

วันที่: 2026-10-07 · แจ้งจาก PROD

## อาการ

เปิดใบโอนจัดสรรปีไหน ยอดเงินเป็นของปีนั้นถูกต้อง แต่รายการขึ้น 2 แถว — รหัสงบประมาณของปี 69 หนึ่งแถว ของปี 70 อีกแถว ยอดเท่ากันทั้งคู่
ตัวอย่าง: ค่าก่อสร้างอาคารสำนักงานอัยการสูงสุด (จังหวัดหนองคาย) category 2614

| ใบโอนปี | แถวที่ขึ้น | ที่ถูก |
|---|---|---|
| 2569 | `...158` = 12,271,700 และ `...167` = 12,271,700 | `...167` แถวเดียว |
| 2570 | `...158` = 5,201,500 และ `...167` = 5,201,500 | `...158` แถวเดียว |

ชื่อ "ยะลา" ที่โชว์ข้างรหัส `...158` บนหน้าจอเป็นแค่ label จาก dropdown (ปี 69 รหัส 158 เป็นของยะลา category 2628)

## สาเหตุ

`OAGWBG_FN_GETBUDGET_ALLOCATE_TRANSFER_CATEGORY` (Oracle function ใน DB ไม่ได้อยู่ใน TFS) มีบรรทัด
`LEFT JOIN OAGWBG_BUDGETCODE_YEAR BCY ON PRODUCTID / ACTIVITYCODEID / CATEGORYID` **ไม่มีเงื่อนไข BUDGETYEAR**
ทั้งในบล็อก BRC (รายการ) และ BATC (ยอดเงิน) — ส่วน BCMY ที่อยู่ติดกันกรองปีครบ

ผลคือ BUDGETCODE_YEAR มีแถวของรายการเดียวกันกี่ปี แถวรับงบ 1 แถวก็แตกเป็นเท่านั้นแถว

- รหัสงบเปลี่ยนข้ามปี → ได้หลายแถว รหัสคนละปี แล้ว BATC จับคู่ด้วยรหัสเดียวกัน ทุกแถวเลยได้ยอดเต็ม (= อาการที่แจ้ง)
- รหัสงบเหมือนกันข้ามปี (หรือรหัสมาจาก BRSC/obc) → แถวไม่แตกให้เห็น แต่ SUM ใน BATC ถูกคูณตามจำนวนปี
  - PROD: category 2296 กิจกรรม 21200 ปี 69 คงเหลือ -364,000 → ถูกคือ -182,000 (x2)
  - PREPROD: เงิน 400 ปี 2568 ถูกคูณ x2/x3 เช่น ใบ 68030003 แสดง 3,000 จริง 1,000

C# (`BudgetService.GetBudgetTransferCategory`) ตัดซ้ำด้วย `DistinctBy(AccountCode, TransferNo)` แต่ AccountCode ต่างกันจึงไม่ถูกตัด

## การแก้

เพิ่ม `AND BCY.BUDGETYEAR = ob.BUDGETYEAR` ที่ join BCY ทั้ง 2 จุด ส่วนอื่นไม่แตะ

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `fix_fn_allocate_transfer_category.sql` | CREATE OR REPLACE ตัวที่แก้แล้ว |
| `rollback_fn_allocate_transfer_category.sql` | DDL เดิมจาก PROD (LAST_DDL_TIME 2026-09-29) ใช้ได้ทั้ง 2 เครื่อง |
| `verify_before_after.sql` | SELECT ตรวจผล มีค่าคาดหวังก่อน/หลังของทั้ง PROD และ PREPROD |

## สิ่งที่พิสูจน์แล้ว (ก่อน deploy, SELECT อย่างเดียว)

1. DDL PROD กับ PREPROD logic ตรงกันทุกบรรทัด (`diff -w` ไม่มีผลต่าง ต่างแค่ tab/space)
2. Dry-run: เอา query ใน function มารันตรงโดยแทนพารามิเตอร์เป็นค่าคงที่
   - เวอร์ชันเดิมได้ผลตรงกับ function ที่ deploy อยู่ (PROD 2569: 739 แถว / 29,810,228,075.55 เท่ากันทุกหลัก) → harness เชื่อถือได้
   - เวอร์ชันแก้: แถวรหัสปีอื่นเป็น 0 บน PROD, 2614/2620/2628 เหลือแถวเดียวรหัสถูกปี
3. เทียบคอลัมน์ทั้งหมดยกเว้นรหัสงบ (DISTINCT แล้ว comm 2 ทาง) บน PROD
   - 2570: 271 = 271 ไม่มีส่วนต่าง → เหลือแค่ตัดแถวซ้ำ ไม่มีรายการหาย ไม่มียอดเปลี่ยน
   - 2569: ต่าง 9 แถว ทั้งหมดคือ category 2296 ที่ยอดเคยถูกคูณ 2 (อธิบายด้านบน)
4. BUDGETCODE_YEAR ไม่มีแถวซ้ำใน ปี+ผลผลิต+กิจกรรม+รายการ เดียวกัน ทั้ง PROD และ PREPROD → หลังแก้ BCY join ได้ไม่เกิน 1 แถว

## ยังไม่ได้ทำ / ต้องตัดสินใจ

- ยังไม่ได้ deploy ทั้ง PREPROD และ PROD
- ใบโอนที่บันทึกไปแล้วโดยเลือกแถวรหัสผิดปี อาจมี AccountCode ผิดค้างอยู่ — ยังไม่ได้ตรวจ
- `OAGWBG_FN_GETBUDGET_RECEIVE_PERIOD_CATEGORY` ก็ join BUDGETCODE_YEAR — ยังไม่ได้ดูว่ามีปัญหาเดียวกันไหม
- ข้อมูลแปลกแยกต่างหาก: ปี 69 รหัส `...167` ผูกกับ 2 รายการ (2614 อาคารสำนักงาน และ 2620 ชุดพักอาศัยฯ หนองคาย) ควรให้ทีมงบประมาณยืนยัน
